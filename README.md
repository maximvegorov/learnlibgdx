# Разработка 2D-игр на Java 25 и LibGDX для Desktop

## Оглавление

1. [Глава 1 Создание проекта](chapters/chapter-01.md) — создание проекта с модулями `core` и `lwjgl3`, знакомство с зависимостями и первый запуск окна приложения.
2. [Глава 2 Игровой цикл и экраны](chapters/chapter-02.md) — жизненный цикл приложения, обновление и отрисовка с учётом времени, разделение игры на экраны и переключение между ними.
3. [Глава 3 Отрисовка 2D-графики](chapters/chapter-03.md) — текстуры и `SpriteBatch`, мировые координаты и камера, настройка `Viewport`, обработка изменения размера окна и отрисовка 2D-фигур через `ShapeRenderer`.
4. [Глава 4 Ресурсы и экран загрузки](chapters/chapter-04.md) — атласы текстур, загрузка через `AssetManager`, экран с индикатором прогресса и освобождение ресурсов.
5. [Глава 5 Шрифты в LibGDX](chapters/chapter-05.md) — TrueType и `BitmapFont`, собственный `FontGenerator`, размеры, размещение и качество текста.
